## Опис функціоналу програми

### 1. Інтерфейс користувача (UI)
* **Головне меню (Навігація):**
  * Перемикання між основними вкладками програми (Огляд, Їжа, Профіль).
* **Головний екран:**
  * Візуальне відображення прогресу спожитих калорій за день (Progress Bar).
  * Відображення статистики макронутрієнтів (білки, жири, вуглеводи).
  * Віджет відстеження водного балансу з кнопками швидкого додавання (+250 мл, +500 мл).
  * Таблиця та історія спожитих страв за поточний день.
  * Попереджувальні повідомлення при перевищенні денного ліміту калорій.
* **Екран додавання прийому їжі:**
  * Поля для введення назви продукту, калорійності на 100г, макронутрієнтів та ваги з'їденої порції.
  * Кнопка для підтвердження та збереження продукту.
* **Екран профілю користувача:**
  * Поля для введення індивідуальних фізичних параметрів.
  * Вибір поточної мети (схуднення, підтримка ваги, набір маси).

### 2. Логіка трекінгу та розрахунків
* **Облік їжі:**
  * Автоматичний розрахунок фінальної калорійності та кількості макронутрієнтів на основі введеної ваги порції за математичною пропорцією.
  * Сувора валідація даних (перевірка на порожні поля, заборона від'ємних значень).
* **Персоналізація цілей:**
  * Динамічне обчислення денної норми калорій залежно від обраної користувачем мети (використання спеціальних алгоритмів-стратегій).
* **Відстеження води:**
  * Облік доданої рідини та миттєвий розрахунок відсотка виконання денної норми гідратації.
* **Реактивність інтерфейсу:**
  * Автоматичне перерахування всіх підсумків та оновлення графіків одразу після додавання нового запису (без перезавантаження сторінки).

### 3. Збереження даних
* **Локальний сервер та файлова система:**
  * Збереження всієї інформації (історія прийомів їжі, налаштування профілю, статистика води) на бекенд-сервері Node.js у форматі `data.json`.
  * Повна ізоляція логіки роботи з даними через спеціальні класи-репозиторії.
* **Автоматичне завантаження:**
  * Відновлення всіх записів та підтягування актуальної статистики при кожному запуску програми або оновленні сторінки браузера.

### 4. Додаткові можливості (необов’язкові)
* Побудова графіків тижневої чи місячної статистики споживання.
* Інтеграція готової бази даних продуктів для вибору зі списку (API).
* Можливість видаляти помилково додані прийоми їжі з історії.
* Експорт щоденника харчування у формат CSV або PDF для друку.
